# 骗局溯源 · 反诈推理师

## 直接体验
双击 `骗局溯源-反诈推理师.html` 即可离线运行，无需安装依赖、无需联网。

## 已实现
- 8 个校园高发骗局案例，共 44 处可点击破绽
- 直接点击聊天文字标记破绽
- 命中、误标、遗漏、提示、计时与 S/A/B/C 评级
- 完整骗术链路复盘与逐条危险点/应对建议
- 本地能力画像、八维雷达图、历史记录
- 截图研判离线演示：上传预览 + 粘贴文字 + 本地规则分析 + 一键转推理关
- 动态效果：证据锁定脉冲、扫描线、评级盖章、雷达绘制、S 级彩带
- 微信手机浏览器适配，支持安全区和触屏操作
- 所有数据仅保存在本地浏览器，不收集个人信息

## 拆分版部署
`index.html`、`styles.css`、`cases.js`、`app.js` 可一起上传到 GitHub Pages、学校服务器或静态托管平台。

## 技术说明
当前截图研判为离线规则引擎演示，不会上传图片或聊天内容。正式接入真实 OCR 与大模型时，应通过云函数调用，API Key 不得放入前端。

## 自测结果
- 8 个案例均可完成 S 级全破绽通关
- 每个案例复盘条目数与破绽数一致
- 误标会扣分并将评级降为 A
- 360px 至 440px 手机宽度无横向滚动
- 单文件版与拆分版均通过浏览器自动通关测试
